# coffee-grounds-packaging
A passion project to develop biodegradable express boxes from spent coffee grounds and other reusable materials. 
📖 Project Overview
This is a Passion Project aimed at developing  biodegradable express packaging materials using spent coffee grounds and other reusable materials. The project documents the entire process from problem identification, literature review, material formulation experimentation, prototype testing, to data analysis.

🧪 Experiments & Data
Experiment Logs: Daily records of experimental design, procedures, observations, and reflections.

Raw Data: Test images, videos, measurement spreadsheets.

Data Analysis: Processed data and preliminary charts.

🔍 Research & References

Literature Review: Summaries of collected academic papers, patents, and industry reports.
